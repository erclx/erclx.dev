# Public repo standards

## Reviewer-facing text

- Do not write a personal name into a commit message, PR body, or other reviewer-facing artifact. Use neutral phrasing instead: "the user", "a recruiter", "a local file"
- Do not cite a `.canon/` path (tasks, plans, review, tmp) from a PR body or other reviewer-facing artifact. Inline the context, or say "queued as a follow-up" instead
